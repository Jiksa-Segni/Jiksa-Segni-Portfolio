# Jiksa Segni — Personal Portfolio

A personal, independent portfolio built with React + Vite. It is not an IBT-branded site. The content is based on Jiksa Segni's CV and the visual direction is inspired by the supplied portfolio screenshot.

## Run

npm install
npm run dev

## Replace before publishing

- `public/profile.jpg` is the supplied profile photo.
- Replace the `#` links for Addis Eats Live Demo and GitHub in `src/main.jsx`.
- If desired, add a CV PDF as `public/Jiksa_Segni_CV.pdf` and add a download button.
- The contact form is currently visual only; connect it to an email/form service before using it in production.
